# ADR 0007: UI foundation and visual equipment layers

**Status:** Accepted

The web application uses Tailwind CSS and owned shadcn/ui source on Radix primitives. Default shadcn styling is not the product design. Veilfall defines its own semantic tokens, variants, surfaces, typography, motion, and game components.

Character appearance uses server-authorized layered assets with a fixed canvas, pose, perspective, lighting, anchors, crop, and z-order. User image uploads are not supported.
